# Monstro da Informática — landing page

Site estático (HTML/CSS/JS puro, **sem build**), publicado no GitHub Pages a partir da raiz da branch `main`.
Domínio: `monstrodainformatica.com` (arquivo `CNAME`). Loja antiga: https://monstrodainfomatica.lovable.app

## Publicar
Commit e push na `main`. O GitHub Pages publica sozinho em ~1 minuto.

## Estrutura
- `index.html` — página principal; uma pasta com `index.html` por serviço (`*-fortaleza/`).
- `fonts/` — fonte Plus Jakarta Sans hospedada aqui (sem chamada ao Google).
- `img/` — imagens em WebP. `sitemap.xml`, `robots.txt`, `404.html`, `favicon.svg`, `og.jpg`.

## Ao criar uma página nova
Adicione a URL no `sitemap.xml`, defina `title`, `meta description` e `canonical` próprios e use um único `h1`.
